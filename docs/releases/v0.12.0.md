## VoiceClear v0.12.0 — Debug 测试版

本 Release 由 GitHub Actions 从对应标签自动构建，提供 **Debug 签名 APK**，可直接安装测试；它不是正式上架签名版本。

### 主要变化

- 修复取消、跨会话停止、迟到结果、PCM/TTS 中断及 ASR/TTS 生命周期问题。
- 加强模型完整性校验、下载重试、staging 和原子发布。
- 研究采集默认拒绝授权，撤回贯穿导出、校验和评测；转写按 segmentId 幂等更新。
- 数据集 ZIP 保留逐段音频与元数据；导入器执行源校验、staging 复验和原子发布。
- 评测严格处理缺失/多余识别、重复 ID、缺音频、空参考文本和授权状态。

完整整改与诚实边界见仓库中的 `CODE_REVIEW_REMEDIATION_2026-11-26.md`。

### 安装

```bash
adb install -r VoiceClear-v0.12.0-debug.apk
```

支持 Android 8.0（API 26）及以上，包含 ARM64 与 ARMv7 native 库。首次使用需要下载 SenseVoice 模型并授予麦克风权限。

### 校验

下载 `SHA256SUMS.txt`，在与 APK 相同的目录执行：

```bash
sha256sum -c SHA256SUMS.txt
```
