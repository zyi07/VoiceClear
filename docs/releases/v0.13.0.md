## VoiceClear v0.13.0 — 普通话与山东方言适配基础

本版本新增普通话/山东方言识别档案、采集提示和分层评测。若通过 GitHub Actions 发布，产物仍为 **Debug 签名测试包**，不是正式上架签名版本。

### 主要变化

- 两种档案均显式使用 SenseVoice `language=zh`，避免自动语种判断把中文误判为粤语。
- 档案持久化并写入识别结果与指标；非忙状态可切换，旧加载任务不会覆盖新档案。
- 新增 36 条山东自然朗读提示，以及冀鲁官话、中原官话、胶辽官话分区元数据。
- 校验与评测支持普通话/山东方言及分区 CER、否定词和数字错误对照。

### 诚实边界

山东档案不是方言专用模型。SenseVoice 没有独立 `shandong` 标签，当前 sherpa-onnx 热词机制也不适用于 SenseVoice；本版不使用热词或强制文本替换伪装适配。

本轮建立可验证的适配基础，**不宣称识别率已经提升**。真实效果必须使用目标人群的普通话和山东方言语料进行同设备、同音源 A/B 验证。

### 自动化验证

以实际 GitHub Actions 日志为准。流水线执行 Python 测试、Android 测试、Lint、Debug 构建、ASR 配置、APK 权限、版本与签名检查，并附 SHA-256。

### 安装与验收

```bash
adb install -r VoiceClear-v0.13.0-debug.apk
```

支持 Android 8.0（API 26）及以上。真机 Gate 3、真实普通话/山东方言语料评测和正式发布签名仍需单独完成。
