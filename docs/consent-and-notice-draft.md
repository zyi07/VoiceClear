## 1. 知情同意书（参与者签署）

### 1.1 研究简介

本研究旨在开发一款帮助言语障碍者「把话说清楚」的安卓手机应用。
我们希望了解特定发音不清人群的真实语音特征，用于改进语音识别与语音合成技术，
使应用输出更易被他人听懂的语音。

本研究属于**语音技术研究**，不提供医疗诊断、治疗建议或康复干预。
参与与否完全自愿，不影响您使用任何其他辅助沟通工具或服务。

### 1.2 您将被邀请做什么

| 环节 | 内容 | 大致耗时 |
|---|---|---|
| 知情同意 | 阅读并签署本同意书 | 约 10 分钟 |
| 基线录音 | 按屏幕提示朗读约 5 句话 | 约 3 分钟 |
| 自发表达 | 用您自己的话说几句想说的话 | 约 5 分钟 |
| 意图确认 | 确认系统或我们是否正确理解了您的话 | 约 3 分钟 |
| 主观评价 | 填写简短问卷 | 约 5 分钟 |

单次参与合计约 20–30 分钟。**您可以随时暂停、跳过任何环节或直接退出，
无需说明理由，也不影响您的报酬。**

### 1.3 我们会记录什么

- **录音**：您的语音录音（原始格式与 16 kHz 副本）；
- **转写**：录音对应的文字，以及您确认的「您本来想说的话」；
- **技术环境**：设备型号、录音时的环境与距离区间、噪声水平；
- **健康相关信息**：由专业顾问评定的障碍严重程度分级（不记录具体诊断名称）；
- **主观评价**：您对识别结果与合成语音的评分。

**我们不会记录**：您的姓名、身份证号、手机号、住址、单位名称。
您的身份以随机编号（如 spk_001）代替，编号与您本人无法直接对应。

### 1.4 语音数据的特殊性（请重点阅读）

语音是**生物特征信息**，与指纹类似，泄露后难以更换。因此本项目采取以下措施：

1. 录音数据默认**仅保存在您的手机上**，研究团队需要时才会通过**单独授权**的方式获取；
2. 数据存储在受控环境中，仅限经授权的研究人员访问；
3. 数据的**保存期限**为研究结束后 [待填写，例如 2 年]，到期后按约定删除；
4. 涉及「您的声音特征」（voice profile，即用您的录音生成可复现您音色的模型）
   是**单独一项授权**，默认不开启；
5. 研究成果中若展示录音或文字案例，会**另行征得您的同意**并做去标识化处理。

### 1.5 可能的风险与不适

- **疲劳**：连续说话可能感到疲劳。设有 20 分钟上限，您可随时暂停；
- **心理不适**：话题涉及就医、买药等场景时可能引起不适，您可跳过相关句子；
- **录音本身无预期风险**，但环境中的他人声音可能被一并录入；
- **无直接健康风险**。您不需要在研究期间改变任何用药或治疗。

### 1.6 您的权利

| 权利 | 说明 |
|---|---|
| 知情同意 | 签署前可要求研究人员解释任何内容 |
| 随时退出 | 任何时候都可以退出，不需理由，不影响报酬 |
| 撤回授权 | 可撤回训练、云端处理、声音特征等任一用途的授权 |
| 数据删除 | 可要求删除您的原始录音与转写数据 |
| 查阅与更正 | 可查看您的数据并要求更正 |
| 无偿退出 | 退出不影响已获得的报酬 |

**关于撤回的技术边界（重要，请务必理解）**：

- 撤回后，我们**立即停止**将您的数据用于新的训练与新的模型；
- 您要求删除的原始录音、转写与派生文件，我们**会删除**；
- 但如果您的数据已经用于训练了**全局共享模型**，我们**无法保证**把您的个人特征
  从已训练完成的模型参数中精确移除。这是当前语音技术的客观限制，
  我们会在您同意前明确说明，不作含糊承诺。

## 2. 分项授权勾选表

每一项**独立**选择，默认全部为「否」。未勾选的项目，数据将不被用于该用途。

```
【必需，仅此一项为参与前提】
  [ ] 1. 同意参与本研究并采集录音与转写（research_use）

【可选，各自独立】
  [ ] 2. 同意将数据用于训练语音识别与合成模型（train_use）
  [ ] 3. 同意将数据上传至受控服务器进行处理（cloud_upload）
  [ ] 4. 同意生成并使用我的声音特征（voice_profile）
  [ ] 5. 同意在匿名统计报告中引用我的数据（anonymous_report）
  [ ] 6. 同意在论文或演示中展示经去标识化的录音/文字案例
```

**撤回方式**：联系上面任一联系方式即可撤回任一项，无需说明理由。

## 3. 研究人员告知文本（现场口头说明稿）

> 建议在采集开始前逐字或大意说明以下内容，让参与者有充分时间提问。

```
您好，我是本项目的研究人员。

这个研究是做一个手机应用，帮发音不太清楚的人把话说得更清楚一点。
我们想了解大家平时真实说话是什么样的，这样我们才能把应用做得更好用。

接下来我会请您：
  1. 读几段屏幕上的句子；
  2. 用您自己的话说几句您想说的话；
  3. 确认我们有没有理解对。

整个过程大概 20 到 30 分钟。

有几点我想特别说清楚：

第一，您随时可以停下来休息、跳过题目，或者直接结束走人。
不需要理由，也不会少拿报酬。

第二，我们不会问您的姓名和身份证号，只会给您一个编号。
但我要如实告诉您：录音本身就是您的生物特征，属于比较敏感的信息。
所以默认只存在您的手机里，我们要用的时候，会另外单独问您。

第三，如果以后您想撤回同意或者要我们删掉数据，随时联系我们就行，不用解释原因。
有一个地方我要提前讲清楚：如果您的录音已经拿去训练过公共模型，
我们没办法保证把您的声音特征从那个已经训练好的模型里精确抹掉。
这是现在这个技术的客观限制，我不想在这一点上给您不切实际的承诺。

第四，这个研究不提供诊断和治疗建议。

您有什么问题吗？没有的话我们就可以开始了。
```
