# VoiceClear 首代 APK 真机测试指引

> 版本：v1.0  
> 构建日期：2026-11-13  
> APK：`app-debug.apk`（debug 签名，可直接安装）

## 1. 安装

```bash
# 方法一：直接传文件
adb install -r VoiceClear-debug.apk

# 方法二：先推到手机再安装
adb push VoiceClear-debug.apk /sdcard/Download/
adb shell pm install -r /sdcard/Download/VoiceClear-debug.apk
```

**要求**：Android 8.0（API 26）及以上。首次启动需授予麦克风权限。

## 2. 抓日志（两种方式，可同时用）

### 方式一：adb logcat（推荐，实时）

```bash
# 只看 VoiceClear 的日志
adb logcat -s VoiceClear:V

# 带时间戳与线程信息
adb logcat -v threadtime -s VoiceClear:V

# 先清空再操作，避免历史日志干扰
adb logcat -c
adb logcat -v threadtime -s VoiceClear:V > voiceclear-log.txt
```

### 方式二：App 内导出（无需连电脑）

主界面底部「**导出诊断日志**」按钮 → 选择保存位置 → 得到 `voiceclear-log-*.txt`。

两种方式内容一致：方式一实时、适合交互过程；方式二可留存、可直接发文件。

## 3. 日志内容说明

日志**不含原始音频，也不含完整表达文本**，只含元信息与错误码：

| Tag | 内容 |
|---|---|
| `Session` | 会话开始、ID 前 8 位 |
| `Capture` | 采集耗时、时长、采样率、质量标记 |
| `Recognition` | 识别耗时、置信度、**文本长度**（不含内容） |
| `Synthesis` | 合成耗时、警告码 |
| `Playback` | 播放耗时 |
| `Metrics` | 各阶段耗时与结果状态 |
| `Error` | 错误信息 |
| `Log` / `Export` | 日志导出与音频导出过程 |

## 4. 建议测试路径

### 4.1 基础功能

1. 启动 App → 授予麦克风权限
2. 点「按住说话」→ 说一句中文 → 停止
3. 观察是否出现「识别文本」框 → 文本是否可编辑
4. 点「确认并播放」→ 听到合成语音
5. 点「播放原始语音」→ 听到自己的原声
6. 点「取消」→ 应能中断

**请记录**：

- 你的手机型号与 Android 版本
- 从停止说话到出现识别文本的**大致秒数**（这是最关键的体验指标）
- 识别文本与您实际说的话差多少（完全一致 / 差几个字 / 完全不对）
- 是否听到合成语音；听起来是否清楚、是否像你
- 是否有卡顿、闪退、听不见、重复播放等情况

### 4.2 边界场景（每个都试一下）

| 场景 | 操作 | 关注点 |
|---|---|---|
| 长停顿 | 说完后停 3 秒再点停止 | 是否被提前截断 |
| 极短语音 | 只说「嗯」一个字 | 是否有异常提示 |
| 快速连续操作 | 连续快速点停止/播放 | 是否状态错乱 |
| 来电打断 | 播放中接个电话 | 是否自动停止、能否恢复 |
| 蓝牙耳机 | 连蓝牙耳机后重复 4.1 | 录音与播放是否走耳机 |
| 静音模式 | 静音后播放 | 是否能听到 |
| 飞行模式 | 开飞行模式 | 是否仍可用（应为纯本地） |
| 后台切换 | 播放时切到其他应用再回来 | 状态是否正常 |

### 4.3 采集模式

主界面「**采集模式**」→ 选提示句 → 录音 → 看是否正确入库与统计。

**注意**：采集模式用于经伦理审查批准的研究采集，正式使用前请勿用它采集真实用户数据。

## 5. 反馈时请附上

1. `voiceclear-log.txt`（adb logcat 或 App 导出）
2. 手机型号 + Android 版本 + 是否使用蓝牙耳机
3. 上述每一步的实际表现，特别是**耗时**与**识别准确度**
4. 任何异常（闪退、无响应、权限问题）的**发生时机**

## 6. 已知限制（测试时请预期到）

- **识别是假引擎**：当前版本不接入真实中文 ASR，识别文本是固定示例文本。
  这一版测的是**交互链路、音频采集、播放、状态机与日志**，不是识别质量。
- **合成用系统 TTS**：声音是通用音色，不保留你的个人音色。
- **端侧性能未验证**：首帧延迟、内存占用、温升需要真机数据才能评估。
- 未做真机适配测试：这是第一次在真机上运行，
  音频路由、焦点抢占、后台行为都可能暴露问题——这正是本次测试的目的。
